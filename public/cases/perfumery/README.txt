The Art of Perfumery / L'art de la parfumerie

OPEN IT
  Double-click  perfumery-standalone.html  (keep the "photos" folder next to it).
  Works offline; no server needed. For the best voices use Microsoft Edge or Google Chrome.

DEVELOPER VERSION
  index.html + js/ + css/ needs a web server:  python3 -m http.server   then open http://localhost:8000
  npm test            runs the tests (needs Playwright)
  npm run build       rebuilds perfumery-standalone.html

PHOTOS
  photos/ holds small crops of Wikimedia Commons photos. Authors and licences are listed in the page footer
  ("Photo credits") and in js/data/photos.js.
